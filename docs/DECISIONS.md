# Журнал решений

Короткие записи о спорных решениях: что выбрали и почему.

## 2026-11-21 — Импорт вместо форка

Код CleanCity скопирован в собственный репозиторий одним коммитом `chore: import CleanCity source`
(без `FUNDING.yml` автора — это его кнопка спонсорства). Так в истории чётко отделено
«взятое» от «добавленного», а связь с оригиналом указана в README и LICENSE.

## 2026-11-21 — Порт API 5050

На macOS порт 5000 занят AirPlay Receiver (процесс ControlCenter), из-за чего оригинал
не запускался. Порт по умолчанию — 5050, прокси Vite обновлён. На Render порт задаёт сама платформа.

## 2026-11-21 — MongoDB в памяти для разработки

Если `MONGODB_URI` не задан и это не production, сервер поднимает `mongodb-memory-server`.
Это позволяет запустить проект без Atlas и без Docker. В production без `MONGODB_URI`
сервер честно падает с ошибкой.

## 2026-11-21 — Секреты в `server/.env`

Сервер читает сначала `server/.env`, потом корневой `.env`. Ключи Gemini и FIRMS
никогда не попадают во фронтенд (переменные без префикса `VITE_` Vite не встраивает).

## 2026-11-21 — `package-lock.json` в git

Оригинал игнорировал lock-файл. Мы его коммитим, чтобы Render и Vercel ставили те же
версии пакетов, что и локально.

## 2026-11-21 — Удалены шаблонные файлы

`SECURITY.md` (незаполненный шаблон GitHub) и `src/App.css` (остаток шаблона Vite, нигде не импортировался).

## 2026-11-21 — Шрифт Inter вместо Manrope

Проверка в браузере показала, что в Manrope нет букв ә, ғ, қ, ң, ұ (браузер подставлял
другой шрифт). Inter Variable (`@fontsource-variable/inter`, подключён локально, без Google Fonts)
содержит все 18 казахских букв (строчные и заглавные) — проверено замером глифов.

## 2026-11-21 — Тёмная карта: OSM + CSS-фильтр

Тайлы CARTO `dark_all` теперь требуют API-ключ («API KEY REQUIRED»). Тёмный слой —
это стандартные тайлы OpenStreetMap с CSS-фильтром (`invert + hue-rotate`, класс `.tiles-dark`).
Бесплатно, без ключа, атрибуция OSM сохранена. Слои «Улицы» и «Спутник» (Esri) остались.

## 2026-11-21 — Эко-категории заведены на шаге 2

Новые категории понадобились уже для дизайна (иконки, цвета, фильтры, переводы), поэтому
они введены вместе с темой, а не на шаге F1. Старые жалобы с прежними категориями показываются как «Другое».

## 2026-11-21 — Состояние карты в URL

Открытая жалоба — `/?r=<id>`, форма новой жалобы — `/?new=1`. Ссылку на жалобу можно
переслать, а лента открывает жалобу прямо на карте. Старые ссылки CleanCity `/map#focus=<id>`
перенаправляются. Отдельная модалка ReportDetail с мини-картой заменена шторкой на главной карте.

## 2026-11-21 — Цвет маркера = серьёзность, иконка = категория

Severity 1–5 задаёт цвет (зелёный → красный) и размер маркера (26–46 px), категория видна по иконке.
Пока ИИ нет, жалобы без severity показываются как 2 («умеренная»).

## 2026-11-21 — Даты в числовом формате

Chrome выводит казахские названия месяцев как «M11», поэтому даты везде числовые (21.11.2026).
