# Журнал решений

Короткие записи о спорных решениях: что выбрали и почему.

## 2026-11-21 — Импорт вместо форка

Код CleanCity скопирован в собственный репозиторий одним коммитом `chore: import CleanCity source`
(без `FUNDING.yml` автора — это его кнопка спонсорства). Так в истории чётко отделено
«взятое» от «добавленного», а связь с оригиналом указана в README и LICENSE.

## 2026-11-21 — Порт API 5050

На macOS порт 5000 занят AirPlay Receiver (процесс ControlCenter), из-за чего оригинал
не запускался. Порт по умолчанию — 5050, прокси Vite обновлён. На Render порт задаёт сама платформа.

## 2026-11-21 — MongoDB в памяти для разработки

Если `MONGODB_URI` не задан и это не production, сервер поднимает `mongodb-memory-server`.
Это позволяет запустить проект без Atlas и без Docker. В production без `MONGODB_URI`
сервер честно падает с ошибкой.

## 2026-11-21 — Секреты в `server/.env`

Сервер читает сначала `server/.env`, потом корневой `.env`. Ключи Gemini и FIRMS
никогда не попадают во фронтенд (переменные без префикса `VITE_` Vite не встраивает).

## 2026-11-21 — `package-lock.json` в git

Оригинал игнорировал lock-файл. Мы его коммитим, чтобы Render и Vercel ставили те же
версии пакетов, что и локально.

## 2026-11-21 — Удалены шаблонные файлы

`SECURITY.md` (незаполненный шаблон GitHub) и `src/App.css` (остаток шаблона Vite, нигде не импортировался).

## 2026-11-21 — Шрифт Inter вместо Manrope

Проверка в браузере показала, что в Manrope нет букв ә, ғ, қ, ң, ұ (браузер подставлял
другой шрифт). Inter Variable (`@fontsource-variable/inter`, подключён локально, без Google Fonts)
содержит все 18 казахских букв (строчные и заглавные) — проверено замером глифов.

## 2026-11-21 — Тёмная карта: OSM + CSS-фильтр

Тайлы CARTO `dark_all` теперь требуют API-ключ («API KEY REQUIRED»). Тёмный слой —
это стандартные тайлы OpenStreetMap с CSS-фильтром (`invert + hue-rotate`, класс `.tiles-dark`).
Бесплатно, без ключа, атрибуция OSM сохранена. Слои «Улицы» и «Спутник» (Esri) остались.

## 2026-11-21 — Эко-категории заведены на шаге 2

Новые категории понадобились уже для дизайна (иконки, цвета, фильтры, переводы), поэтому
они введены вместе с темой, а не на шаге F1. Старые жалобы с прежними категориями показываются как «Другое».

## 2026-11-21 — Состояние карты в URL

Открытая жалоба — `/?r=<id>`, форма новой жалобы — `/?new=1`. Ссылку на жалобу можно
переслать, а лента открывает жалобу прямо на карте. Старые ссылки CleanCity `/map#focus=<id>`
перенаправляются. Отдельная модалка ReportDetail с мини-картой заменена шторкой на главной карте.

## 2026-11-21 — Цвет маркера = серьёзность, иконка = категория

Severity 1–5 задаёт цвет (зелёный → красный) и размер маркера (26–46 px), категория видна по иконке.
Пока ИИ нет, жалобы без severity показываются как 2 («умеренная»).

## 2026-11-21 — Даты в числовом формате

Chrome выводит казахские названия месяцев как «M11», поэтому даты везде числовые (21.11.2026).

## 2026-11-21 — TypeScript

Весь код переведён на TypeScript в строгом режиме (`strict`). Фронт собирает Vite, сервер
запускается через `tsx` (без отдельной компиляции — проще деплой на Render). Три tsconfig:
`tsconfig.app.json` (браузер), `tsconfig.server.json` (Node), `tsconfig.node.json` (vite.config).
`npm run build` сначала делает `tsc -b`, поэтому ошибка типов ломает сборку.

## 2026-11-21 — shadcn/ui (Radix, пресет nova)

Кнопки, бейджи, карточки, выпадающие меню, тосты, подсказки, поля форм — из shadcn/ui.
Это не npm-библиотека, а исходники в `src/components/ui`, которые можно править. Правки:
`sonner` без `next-themes` (тема всегда тёмная), у `DrawerContent` добавлен проп `overlay`.
CLI предложил шрифт Geist — убран: для казахского нужен Inter (см. выше).
Шторка на карте — shadcn Drawer (vaul) в немодальном режиме: снизу на телефоне
(можно смахнуть), справа на компьютере; карта при этом остаётся кликабельной.

## 2026-11-21 — Глобальные стили без классов

`src/styles/base.css` задаёт вид семантических тегов: `main` (отступы страницы под панелями),
`main > header`, `h1–h3`, `p`, `small`, `time`, `dl/dt/dd`, `figure`, `fieldset/legend`, ссылки в тексте.
Повторяющиеся поверхности задаются data-атрибутами, а не классами: `data-surface="glass"`,
`data-scroll="x"`, маркеры карты — `data-marker`, `data-selected`, `data-new`.
Цвета и размеры — только через токены в `tokens.css` (переменные shadcn в палитре Taza).
Исключение одно: `.tiles-dark` — Leaflet принимает для тайлов только `className`.

## 2026-11-21 — Страницы на всю ширину

Убрано центрирование `max-w-*`: контент страниц выровнен по краям верхней панели
(`--page-gutter`), сетки расширяются до 4 колонок на широких экранах.

## 2026-11-21 — Бэкенд остаётся Express + MongoDB, Supabase — только для фото (опционально)

Supabase в оригинале использовался лишь как S3-хранилище фото (в CSP). Бэкенд по ТЗ —
Express на Render + MongoDB Atlas. Для фото рекомендуем Supabase Storage (бесплатно, через
уже готовые переменные `S3_*`), потому что диск бесплатного Render стирается при каждом деплое.

## 2026-11-21 — Лимит фото 5 МБ и белый список MIME

По ТЗ сервер принимает до 5 фото по 5 МБ, только jpeg/png/webp/heic/heif/gif; ошибки Multer
возвращаются JSON-ом (413/400). Описание обрезается до 2000 символов, заголовок — до 120.

## 2026-11-21 — F1: модель Gemini и запасные модели

`gemini-2.5-flash` новым ключам уже недоступна (404). Основная модель — `gemini-3.8-flash`
(`GEMINI_MODEL`), запасная — `gemini-3.1-flash-lite` (`GEMINI_FALLBACK_MODELS`). На бесплатном
тарифе модели часто отвечают «перегружена» (503) или не отвечают вовремя, поэтому у каждой попытки
таймаут 20 с, а упавшая модель пропускается 5 минут. Вызов идёт через `@google/genai`, строгий JSON —
через `responseSchema`; ответ дополнительно проверяется на сервере (категория из списка, severity 1–5).

## 2026-11-21 — F1: что уходит в Gemini

Только фото (до 3 штук, уменьшенные до 1024 px) и текст «Что вы видите?». Координаты и данные
пользователя не отправляются. `sharp` пересохраняет фото без EXIF, поэтому GPS из метаданных снимка
тоже не уходит. Под полем текста — предупреждение не писать имена, телефоны и адреса.
Фото для анализа хранятся только в памяти запроса и нигде не сохраняются.

## 2026-11-21 — F1: черновик ИИ правит автор, публикует человек

ИИ заполняет заголовок, категорию, серьёзность и описание; всё это можно изменить до публикации.
Вместе с жалобой сохраняется блок `ai` (исходные категория/серьёзность ИИ, уверенность, что видно,
что делать, модель и флаг `edited`), а в карточке показывается «Оценка ИИ, может ошибаться».
Если ИИ решил, что на фото нет экологической проблемы (`relevant: false`), кнопки публикации нет.

## 2026-11-21 — F1: режим «Заполнить без ИИ»

Если лимит бесплатного Gemini исчерпан или ИИ недоступен, жалобу можно заполнить вручную —
иначе сайт перестал бы работать вместе с чужим сервисом. Такие жалобы сохраняются без блока `ai`.
Блок `ai` присылает браузер, поэтому теоретически его можно подделать; для учебного проекта
это приемлемо (подпись ответа ИИ на сервере — возможное улучшение).

## 2026-11-21 — Rate limit 10 запросов в минуту

`express-rate-limit` на `/api/ai/*`: 10 запросов в минуту с одного IP, ответ 429 с кодом
`rate_limited`. `app.set("trust proxy", 1)` — чтобы за прокси Render считался реальный IP.

## 2026-11-21 — F2: обращение собирается из двух частей

Gemini пишет только тему, описание проблемы и пункты «Прошу». Адресата, место (координаты
и ссылку на OpenStreetMap), дату, число фото и ссылку на карточку подставляет сервер.
Так координаты не уходят в Gemini, а ИИ не может выдумать адрес или дату.
Адресат выбирается правилом по категории, а не ИИ: нефть, вода, выбросы, гибель животных —
Департамент экологии по Атырауской области; свалки, сжигание, деревья, другое — аппарат акима
города Атырау. В интерфейсе он подписан как «рекомендуемый, проверьте в eOtinish».
Текст кэшируется в жалобе отдельно для ru и kk, повторная генерация — по кнопке.

## 2026-11-21 — F2: мы ничего не отправляем

Только кнопки «Копировать текст», «Скачать фото» и ссылка на eotinish.kz. Подаёт житель
сам, войдя через eGov, поэтому ФИО и контакты заявителя у нас не хранятся и в текст не попадают.

## 2026-11-21 — F2: статусы и «Устранено» от трёх жителей

Статусы идут только вперёд: `open → appeal_sent → answered` (кнопки «Я подал(а) обращение»
и «Получен ответ»), `resolved` — только когда 3 разных устройства подтвердили фото «после».
Аккаунтов нет, поэтому «разный житель» = разное устройство: браузер хранит случайный id,
сервер — только его хэш с солью (`CLIENT_ID_SALT`) и не отдаёт его наружу. Очистка браузера
позволит подтвердить ещё раз — для учебного проекта это приемлемо, защита — лимит 20 запросов
в минуту и обязательное фото. Старая кнопка CleanCity «Проблема устранена» (сразу resolved) убрана;
сервер теперь отвечает на такой запрос ошибкой `needs_confirmations`.
Смену статусов без входа в аккаунт может сделать любой — тоже осознанное упрощение.

## 2026-11-21 — F3: Open-Meteo через наш сервер, кэш 15 минут

Open-Meteo работает без ключа, но браузер всё равно ходит в `/api/air`, а не напрямую:
так один запрос к Open-Meteo раз в 15 минут обслуживает всех посетителей (кэш в памяти сервера
с защитой от одновременных запросов, `server/cache.ts` — пригодится и для FIRMS). Если
Open-Meteo недоступен, показываем последние данные с пометкой. Точка — центр Атырау.
Честная оговорка в интерфейсе: это прогноз модели CAMS для квадрата ~10 км, а не измерения
станций. Атрибуция Open-Meteo и Copernicus CAMS, лицензия CC BY 4.0 — под данными.

## 2026-11-21 — F3: чистые часы считает сервер, а не ИИ

«Самые чистые часы» — два непересекающихся двухчасовых окна с 07:00 до 22:00 в ближайшие
24 часа с наименьшим средним US AQI. Их считает код, ИИ получает готовые окна и только
формулирует совет — так он не может выдумать время. Цвета US AQI — стандартные цвета EPA
(`--aqi-*` в tokens.css), рядом всегда подпись категории.

## 2026-11-21 — F3: профиль для плана — две кнопки, без личных данных

В Gemini уходят только группа (взрослый, дети, пожилой, болезни лёгких или сердца,
беременность) и занятие (прогулка, спорт, дорога, дети на улице, проветривание) плюс данные
о воздухе. Это не привязано к человеку. План кэшируется на 15 минут для одинаковых профилей,
с пометками «Оценка ИИ, может ошибаться» и «Это не медицинская рекомендация».

## 2026-11-21 — Навигация: «Воздух» в нижнем меню

В нижнем меню телефона места на пять пунктов: Карта, Жалобы, кнопка, Воздух, Статистика.
«О проекте» на телефоне — иконка ⓘ в верхней панели. На карте добавлен значок текущего AQI,
он ведёт на страницу «Воздух».

## 2026-11-21 — F4: FIRMS — 7 дней двумя запросами, три спутника, кэш 3 часа

API FIRMS теперь отдаёт не больше 5 дней за запрос, поэтому неделя = окно на 5 дней
(с D-6) + окно на 2 дня (с D-1). Берём VIIRS 375 м NRT со всех трёх спутников (Suomi NPP,
NOAA-20, NOAA-21); если один источник не ответил, показываем остальные. Ответ кэшируется на
3 часа, при сбое NASA — последние данные с пометкой. Ключ `FIRMS_MAP_KEY` только на сервере.

## 2026-11-21 — F4: прямоугольник области

Запрос к FIRMS принимает только прямоугольник. Сначала взяли 46.4–56.0° в.д. × 44.8–49.8° с.ш.,
но самые крупные группы точек оказались в Астраханской области и Калмыкии (Россия). Прямоугольник
сужен до 48.5–55.8° в.д. × 45.2–49.4° с.ш.: восточнее дельты Волги. Он всё равно примерный
(захватывает края соседних областей и Каспий), в интерфейсе это подписано: «Атырауская обл. (примерно)».
Точнее можно сделать фильтром по полигону границы области — возможное улучшение.

## 2026-11-21 — F4: «тепловая аномалия», а не «пожар»

VIIRS видит горячие точки: пожар, газовый факел или другую нагретую поверхность. Везде пишем
«тепловая аномалия» и поясняем, что это не подтверждённый пожар. Точка, у которой в радиусе 1 км
есть обнаружения в 3+ разных дня, помечается как «повторяется» (вероятно, постоянный источник) —
без названий предприятий. В ИИ-сводку уходят только агрегаты: количество, дни, группы точек
(в радиусе 5 км) с расстоянием и направлением от Атырау. Называть компании и объекты ИИ запрещено.

## 2026-11-21 — Третья запасная модель Gemini

Во время проверки F4 обе модели одновременно ответили 503 «перегружена». Добавлена третья
модель: `gemini-3.5-flash-lite`. Цепочка: `gemini-3.8-flash` → `gemini-3.5-flash-lite` →
`gemini-3.1-flash-lite`. Тексты ошибок ИИ в плане, обращении и сводке больше не предлагают
«заполнить вручную» — это подходит только к форме жалобы.

## 2026-11-22 — Демо-данные: 12 придуманных жалоб с рисунками

Для показа проекта есть 12 демо-жалоб (русский и казахский, все категории и все четыре статуса,
две «устранены» с тремя фото «после»). Всё выдумано: места условные, без компаний и людей,
вместо фото — простые рисунки, которые сервер рисует сам (`server/seed/illustrations.ts`).
У каждой `demo: true` и бейдж «Демо» в ленте и карточке.
Локально (MongoDB в памяти) они создаются сами при запуске `npm run dev`. Для Atlas — `npm run seed`
(`--reset` пересоздать, `--remove` удалить) или переменная `SEED_DEMO=1` на сервере.

## 2026-11-22 — Состояния загрузки и ошибок

Если сервер не ответил, на карте вместо подсказки появляется «Нет связи с сервером» с кнопкой
«Повторить». Если загрузка идёт дольше 6 секунд, показываем «Сервер просыпается…»: бесплатный
Render засыпает после 15 минут без запросов, и первый запрос может идти до минуты.

## 2026-11-22 — Казахские даты и заголовок вкладки

Chrome для локали `kk` выводит даты как 2026-11-20. В Казахстане пишут 20.11.2026, поэтому для
казахского используется числовой формат `ru-KZ`. Заголовок вкладки браузера теперь тоже
переводится. В статистике плитка «Открыто» переименована в «Не устранено», чтобы не путать
со статусом «Открыта» в блоке «Путь жалоб».
